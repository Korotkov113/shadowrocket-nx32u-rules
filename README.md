# Актуальные правила Shadowrocket

Компактный конфиг для селективного проксирования: выбранные сервисы идут через `PROXY`, остальной трафик — через `DIRECT`.

Репозиторий ежедневно собирает Shadowrocket-совместимые правила из открытых списков [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains):

- [`rules/domains.list`](rules/domains.list) — домены в формате `DOMAIN-SUFFIX`;
- [`rules/ipv4.list`](rules/ipv4.list) — IPv4-подсети в формате `IP-CIDR`;
- [`shadowrocket.conf`](shadowrocket.conf) — обезличенный пример конфига без прокси-узлов и персональных DNS-адресов.

## Установка

Добавьте в Shadowrocket удалённый базовый конфиг по адресу:

```text
https://raw.githubusercontent.com/Korotkov113/shadowrocket-nx32u-rules/main/shadowrocket.conf
```

В нём прописан `update-url` на самого себя. Поэтому Shadowrocket может обновлять не только два ruleset, но и весь базовый конфиг при будущих исправлениях.

Либо используйте два стабильных URL правил в своём конфиге:

```ini
RULE-SET,https://raw.githubusercontent.com/Korotkov113/shadowrocket-nx32u-rules/main/rules/domains.list,PROXY
RULE-SET,https://raw.githubusercontent.com/Korotkov113/shadowrocket-nx32u-rules/main/rules/ipv4.list,PROXY,no-resolve
```

В Shadowrocket включите `Настройки → Конфигурация → Автоматическое фоновое обновление`, а в iOS — фоновое обновление приложения. Для немедленной загрузки откройте конфиг и нажмите «Обновить конфигурацию», «Использовать конфигурацию» или «Компилировать».

## Персональный DoH без утечки и перезаписи

Публичная база использует обычный AdGuard DNS-over-HTTPS через выбранный прокси. Автообновление целиком перезаписывает локальные правки базового файла, поэтому персональный DoH нельзя добавлять прямо в него.

Используйте штатную расширенную конфигурацию Shadowrocket:

1. Импортируйте публичный базовый конфиг по URL выше.
2. В его меню выберите «Расширить конфигурацию» / `Extend Configuration`.
3. В созданной локальной конфигурации переопределите только `dns-server`, указав свой DoH с `#proxy`.
4. Используйте локальную расширенную конфигурацию: она имеет приоритет, а включённая публичная база продолжает обновляться.
5. Для нескольких своих устройств включите `Данные → iCloud → Автоматическая синхронизация` либо повторите эти четыре шага на каждом устройстве.

Не публикуйте URL персонального DNS. Если расширение не используется, оставьте личный локальный конфиг без `update-url`: тогда автоматически обновятся ruleset, но не весь файл.

## Обновление

GitHub Actions запускает генератор каждый день в 03:17 UTC и коммитит изменения только при изменении upstream-списков. Локальная проверка правил и базового конфига:

```bash
python3 scripts/update_rules.py --check
```
